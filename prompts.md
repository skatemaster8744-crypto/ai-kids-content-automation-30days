# Prompt Pack

## Short Script Prompt
Write a 30-second kids nursery rhyme with:
- cute cartoon baby
- farm animals (goat, cow, horse, chicken)
- simple rhyming words
- happy mood
- sound effects like baa, moo, cluck, neigh
- suitable for YouTube Shorts
- ages 2-5

## Long Video Prompt
Write a 7-minute kids story where a baby explores a farm, meets different animals, learns kindness and friendship, and ends with a bedtime or happy finish. Keep the narration gentle, warm, and easy to understand.

## Image Prompt
Create a cute 3D cartoon baby with big eyes, yellow shirt, blue shorts, green farm background, soft sunlight, cheerful expression, bright colors, cartoon style, 4K.

## Animal Prompt
Create a cute cartoon goat/cow/horse/chicken in a green meadow, friendly face, cheerful look, bright sunlight, clean background, 4K.

## Thumbnail Prompt
Create a bright YouTube thumbnail with a baby and farm animals, simple composition, warm colors, clean text area, happy mood, 4K.

## Voiceover Prompt
Narrate in a warm, gentle, cheerful tone. Keep sentences short, use clear pronunciation, and add soft pauses.
