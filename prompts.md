# Prompt Library

## Short script prompt
Write a 30-second kids nursery rhyme with:
- cute cartoon baby
- farm animals (goat, cow, horse, chicken)
- simple rhyming words
- happy mood
- sound effects like baa, moo, cluck, neigh
- YouTube Shorts format
- beginner-friendly and easy to understand

## Long script prompt
Write a 7-minute kids story where a baby explores a farm, meets different animals, learns kindness, and ends with a bedtime or happy finish. Keep narration gentle, warm, and simple for ages 2-5.

## Image prompt
Create a cute 3D cartoon baby with big eyes, yellow shirt, blue shorts, green farm background, bright sunlight, soft shadows, cartoon style, cheerful expression, 4K.

## Animal prompt
Create a cute cartoon goat with a happy face, soft fur, green meadow background, bright daylight, friendly eyes, colorful and clean, 4K.

## Thumbnail prompt
Create a bright YouTube thumbnail with a baby and farm animals, huge friendly face, warm colors, clean composition, text area left or center, clean and readable, 4K.

## Voiceover prompt
Narrate in a warm, gentle, cheerful kid-friendly tone. Keep sentences short. Add pauses between clauses. Use clear pronunciation and soft emotional expression.

## Caption prompt
Generate short, readable subtitles for a 30-second kids video. Keep each subtitle short, readable, and easy for young children to follow.
